# Registro de uso de IA

Atividade: site React + Vite com IA (tema: página inicial do PFC/TCC).
Este arquivo documenta como a IA foi usada, como pede o objetivo da atividade
(aprender a pedir, revisar, corrigir e melhorar o código gerado).

## Fluxo: ideia → protótipo → código → ajustes → entrega

1. **Ideia** – Enviei o enunciado, os slides da aula e o link do EduGuru e pedi um site
   com no mínimo 5 páginas.
2. **Protótipo** – A IA propôs a estrutura: Início, Sobre, Funcionalidades, Tecnologias, Contato.
3. **Código** – Gerou o projeto Vite + React com React Router e os dados separados em `src/data/content.js`.
4. **Ajustes** – (preencha) o que você revisou, mudou ou corrigiu depois.
5. **Entrega** – Código no GitHub e publicação na Vercel.

## Prompt principal usado

> Fazer um site com React + Vite, página inicial do meu PFC/TCC (EduGuru), moderna e
> bem estruturada, com no mínimo 5 páginas. Entrega no GitHub e na Vercel.
